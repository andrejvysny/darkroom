# Astra call log

Every `/codex-darkroom` invocation, one line. Astra runs on a limited ChatGPT Plus allowance — this
file is how the burn stays visible across sessions, and how a truncated run is picked up later.

`Outcome` is `complete`, `PARTIAL` (usage limit or truncation — see the FINDINGS id for which
sections arrived), or `failed` (with the reason). `Tokens` is the `tokens used` figure from the
run's stderr log — the only direct read on quota burn.
